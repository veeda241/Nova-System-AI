## 🔥 What's New in v2.0 (Evolution Release)

NOVA has evolved from a simple chatbot into a **Multi-Model Autonomous Agent**. It now features:

- **🧠 Multi-Model Neural Bridge**: Automatic failover between **Groq (Llama-3 70B)**, **Gemini 1.5**, **OpenAI**, and **Ollama**.
- **🤖 Autonomous MCP Agent**: Fully capable of planning, generating code, and executing tasks like opening apps or searching the web without human intervention.
- **🖥️ Nova OS (Laptop Interface)**: A premium, Jarvis-inspired graphical HUD with real-time system stats, animations, and "Eye of Nova" vision analysis.
- **⚡ Unified Control Engine (UCE)**: Premium automation layer with Human-Action Simulation (HASE) and App Control Layers (AWCL).
- **📈 Neural Evolution**: A self-optimization engine that allow's Nova to "train" itself on your workflows.
- **📱 Universal Connectivity**: Control your PC from anywhere via Web Dashboard, Bluetooth, or BLE.

## 🚀 Quick Start

### 1. Configure Backends
Create a `.env` file in the root directory:
```env
GROQ_API_KEY=your_key_here
GEMINI_API_KEY=your_key_here
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Launch Nova
```bash
python nova_cli.py
```

## 🧬 System Architecture

### 1. The Multi-Model Brain
Nova's brain is now decentralized. It prioritizes the fastest available model:
1. **Groq Llama 3** (Millisecond response)
2. **Gemini 1.5** (Deep reasoning)
3. **Local Ollama** (Privacy & Offline)

### 2. Autonomous Loop (Observe-Think-Act)
When given a complex goal, Nova's Agent engages in a **ReAct loop**:
- **Think**: Analyzes the goal and breaks it into steps.
- **Act**: Executes tools (Python, Shell, Web Search).
- **Observe**: Inspects results and self-corrects if errors occur.

### 3. Peripheral Core
Control your PC remotely:
- **Bluetooth Terminal**: Pair your phone and send shell commands.
- **Web Dashboard**: A React-style interface for system monitoring.
